# 钱币鉴定盒标签

仓库地址：https://github.com/free361/coin-slab-label-printer

这个工具在自己的电脑上填写钱币资料，再印成鉴定盒上的小标签。一条钱币印一张。程序按 A4 纸自动排列，尽量多放、少费纸。不用再做图，也不用把标签一张张拼到纸上。

页面固定在一屏里。左边填写，上面有两张小标签：左边一张写每个空的名字，右边一张是正在填的字。右边是已经录入的列表。字多了只在自己的框里滚动。

## 需要安装的软件

这个工具在 **Windows** 上使用。打开它靠的是 `启动标签工具.bat`，这个文件只在 Windows 里能双击运行。

要装的只有下面两样，不用再装别的编程软件。

1. **Python 3.7 或更高版本。**  
   程序用了 Python 3.7 才有的本机网页功能，所以 3.7 以下不行，Python 2 也不行。  
   打开 https://www.python.org/downloads/ ，下载 Windows 安装包。页面上的最新正式版都比 3.7 新，选它即可。  
   安装时，第一页一定要勾选 **Add python.exe to PATH**（有的安装包写成 Add Python to PATH）。不勾的话，后面双击打不开。  
   **不用 pip 安装任何包。** 程序只用 Python 自带的功能，没有第三方库。装完 Python 就够了，不要再运行 `pip install`。

2. **浏览器：Microsoft Edge 或 Google Chrome。**  
   Windows 一般已经带了 Edge，可以直接用。没有的话，安装 Edge 或 Chrome 其中一个。

装好这两样之后，再按下一节打开。

## 在 Windows 上怎么打开

先确认上一节的 Python 和浏览器已经装好。不要直接双击 `index.html`。那样不能保存，录入的钱币会丢。

程序到 `server.py` 旁边找一个叫 `web` 的文件夹，并从那里打开网页。字体要放在 `web\fonts\ctlishu.ttf`。这个仓库下载下来时，页面文件和字体还跟 `server.py` 放在同一层，还没有这两个文件夹。不先放好，双击后黑窗口会说找不到 `web` 文件夹，然后退出。

请按这个顺序做：

1. 把整个文件夹保存到电脑上。
2. 在这个文件夹里新建一个文件夹，名字就叫 `web`。
3. 把 `index.html`、`app.js`、`style.css` 移进 `web`。
4. 在 `web` 里面再新建一个文件夹，名字叫 `fonts`，把 `ctlishu.ttf` 移进去。
5. 双击 `启动标签工具.bat`。
6. 会弹出一个黑窗口，接着浏览器打开页面。黑窗口不要关。关了，网页就停了。
7. 用完后关掉黑窗口。下次再双击那个 bat。

如果浏览器没有自动打开，自己在地址栏输入：

`http://127.0.0.1:8765`

这个地址只在你自己的电脑上能打开。如果工具已经开着，再双击一次，只会把网页再打开，不会开第二个。

黑窗口如果写着 `Python was not found`，就是还没装 Python，或者安装时没有勾选 Add python.exe to PATH。回到上面「需要安装的软件」重装一次。

## 页面上能做什么

### 填写和保存

每一条钱币可以填这些：

| 填写项 | 印在标签上吗 | 说明 |
| --- | --- | --- |
| 钱币名称 | 印，左上大字 | 必填。例如：郡国五铢 |
| 版别 | 印，右上，和名称同一行 | 例如：穿上横文 |
| 朝代 | 印，左下大字 | 例如：西汉 |
| 公元年 | 印，下面第二行 | 例如：前118年 |
| 性质 | 印，版别下面 | 例如：一型-郡守十四-114 |
| 编号 | 印在标签右上角，一串数字 | 不填，或和已有编号重复，会按当天日期自动生成。2026 年 11 月 4 日得到的是 2611040001，后面四位按顺序加，不会重复 |
| 直径、厚度、重量 | 印成一行 | 直径和厚度都填时，会变成 `25.5x1.9mm 4.1g` 这种样子 |
| 铸造年代 | 印，下面第一行 | 例如：汉武帝元狩五年至元鼎二年 |
| 备注 | 不印 | 只在列表里提醒自己 |

点 **保存这条**。钱币名称没填时不会保存。

勾着「保存后保留本条数据，方便录下一条」时，刚填的字会留在表单里，编号会换成下一个新的，改一改再保存就是下一条。去掉勾，保存后表单会清空。这个勾选会记住。

点 **清空**，表单里的字会清掉。

打开页面时，如果表单是空的，右边那张示例会先显示第一条已保存的钱币。一开始打字，它就改成正在填的内容。字太长时，程序会自动把字缩小。再放不下，页面会写「有字太长，标签里放不下。请写短一点。」

### 列表

右边可以：

- 搜索。输入框写的是名称、编号、性质、版别。朝代、铸造年代、公元年、备注也能对上。
- 用「全部」「未打印」「已打印」筛选。
- **全选**、**全不选**：只针对现在看得到的那些。
- **勾上未打印的**：勾上所有还没打印的。
- 每条旁边的 **修改**：把这条填回左边。保存后还是这一条，不会多出一条。正在修改时，按钮会变成「保存修改」，也可以点「取消修改」。
- **复制**：照着这条填到左边。改完再保存，才会多出一条，原来的还在。
- **删除选中**：先要勾上。会再问一次。删掉后，上一份数据留在 `data\coins.bak.json`。
- **把选中的标成已打印**、**标成未打印**：只改标记，不打印。
- **下载备份**：下载一个名叫「钱币标签备份.json」的文件，请存到别处。
- **从备份恢复**：选一份以前下载的 json。它会替换现在列表里的全部钱币。没有名称的条目不会恢复。替换前，现在这份会先留在 `data\coins.bak.json`。

新保存的一条会自动勾上，并标成未打印。列表下面会写出一共多少条、选了多少条、要印多少张、一张 A4 能放多少张、需要几页。

### 打印

1. 勾选要印的钱币。
2. 点 **看排版并打印**。左边是按钮和说明，右边是竖着的 A4。没勾选时这个按钮是灰的。
3. 间距可以选，选好后会记住：
   - 省纸，间距 2 毫米：一张 A4 放 48 张（4 列 × 12 行）
   - 好裁，间距 3 毫米：44 张（4 列 × 11 行）
   - 宽松，间距 4 毫米：44 张（4 列 × 11 行）
4. 「显示裁切边框」默认开着。外圈黑线用来下刀，里面有一条细金线。关掉后，这两圈线不画。这个选择会记住。
5. 点 **开始打印**。请用这个按钮。不要在填写页面直接按 Ctrl+P，那样印不出准备好的纸。屏幕上的按钮不会印上去。
6. 打印窗口关掉后会再问一次。已经打出来了就点「确定」，这几条会标成已打印。还没打、或打坏了，点「取消」。

纸的四周会留空白，免得打印机吃掉最外面一圈。间距 2 毫米时，左右大约 12 毫米、上下大约 14 毫米。间距 3 毫米时，左右大约 11 毫米、上下大约 21 毫米。间距 4 毫米时，左右大约 9 毫米、上下大约 16 毫米。页面上会写出当前这一次的留白。

打印窗口里请这样设：

1. 纸张：A4，方向：纵向
2. 边距：无
3. 缩放：100%（不要选「适合页面」）
4. 勾选：背景图形（不然标签底色印不出来，会变成白底）
5. 取消：页眉和页脚

标签底是浅金色，字是黑色。名称和朝代是 10 磅。版别、性质、尺寸、铸造年代、公元年是 6 磅。右上角编号是 5 磅，用微软雅黑。

一张标签宽 44.97 毫米、高 20.51 毫米。

标签上的字优先用 `web\fonts\ctlishu.ttf`。找不到这个文件时，会改用电脑里的「华文隶书」或「隶书」。

## 数据放在哪

程序第一次打开网页时，如果还没有 `data\coins.json`，会自己建 `data` 文件夹，并写入两条「郡国五铢」示例。可以改，也可以删。删光之后，只要这个文件还在，就不会再自动加回示例。第二条示例的备注写着：打印前请核对文字。

- 正在用的：`data\coins.json`
- 每次保存前留下的上一份：`data\coins.bak.json`
- 文件读坏时：程序会把它改名为 `data\coins.bad.json`，请不要删

不要删除 `data` 文件夹。删了，录入的钱币就没了。

仓库根目录里的 `coins.json` 和 `coins.bak.json` 只是放在仓库里的两份数据。程序启动时不会自动去读它们。想用的话，在页面上点「从备份恢复」，再选那个文件。

## 文件各是干什么的

- `README.md`：这份使用说明
- `readme.md`：更早的一份说明。里面写到 PSD 还在 `docs` 里、公开仓库没有字体。这两点和现在的仓库不一样。打开方式和数据位置，以这份 README 为准
- `启动标签工具.bat`：在 Windows 上双击它来打开工具
- `server.py`：在本机开网页，并把录入的钱币写进 `data` 文件夹
- `index.html`：填写、列表和打印的页面。要放在 `web` 文件夹里
- `app.js`：录入、排版和打印是怎么做的
- `style.css`：页面和标签的样子，并指定字体文件的位置
- `ctlishu.ttf`：标签用的字体。要放到 `web\fonts\ctlishu.ttf`
- `coins.json`：仓库里的一份钱币数据，程序不会自动使用
- `coins.bak.json`：仓库里的另一份备份数据，程序不会自动使用

## 常见问题

**网页打不开。**  
看黑窗口里的字。如果写找不到 `web` 文件夹，按上面的步骤把 `index.html`、`app.js`、`style.css` 放进 `web`。如果写 `Python was not found`，按「需要安装的软件」安装 Python 3.7 或更高版本，并勾选 Add python.exe to PATH。不用 pip 安装任何包。地址是 `http://127.0.0.1:8765`。

**标签底是白的。**  
打印时没有勾「背景图形」。

**边上被切掉一截。**  
边距要选「无」，缩放要 100%，并关掉页眉和页脚。

**字看起来不像原来的隶书。**  
确认 `ctlishu.ttf` 放在 `web\fonts\ctlishu.ttf`，然后刷新网页。放错位置时，会改用系统里的隶书。编号本来就是微软雅黑。

**不小心删了。**  
用「从备份恢复」，或去看 `data\coins.bak.json`。如果文件被改坏，去看 `data\coins.bad.json`。
