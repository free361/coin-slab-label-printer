# 钱币鉴定盒标签

这个工具用来打印钱币盒子上的小标签。不用再做 PSD，也不用把很多标签手动拼到一张纸上。

页面固定在一屏里。左边是填写，上面两张小标签跟着左边的宽度变大变小：一张写每个空的名字，一张是你正在填的字。右边是已录入的列表。字多了只在自己的框里往下滚，整页不会跟着跑。程序会按 A4 自动排好，尽量铺满，少费纸。

## 怎么打开

1. 双击文件夹里的 `启动标签工具.bat`。
2. 会弹出一个黑窗口，接着浏览器打开页面。
3. 黑窗口不要关。关了，网页就停了。
4. 用完后关掉黑窗口。下次再双击那个 bat。

如果浏览器没自动打开，自己在地址栏输入：

`http://127.0.0.1:8765`

请用 Edge 或 Chrome。不要直接双击 `web` 文件夹里的网页，那样不能保存。

电脑需要已经安装 Python。安装时要勾选 “Add python.exe to PATH”。

## 怎么录入

每一条钱币填这些：

| 填写项 | 印在标签上吗 | 说明 |
| --- | --- | --- |
| 钱币名称 | 印，左上大字 | 例如：郡国五铢 |
| 朝代 | 印，左下大字 | 例如：西汉 |
| 版别 | 印，右上，和名称同一行填写 | 例如：穿上横文 |
| 性质 | 印，版别下面，左边和版别对齐 | 例如：一型-郡守十四-114。原来的「编号」改成了这个 |
| 编号 | 印在标签右上角，一串数字 | 不填会按当天日期自动生成，例如 2610300001，不会和已有的重复 |
| 直径、厚度、重量 | 印成一行，左边和版别对齐 | 会变成 `25.5x1.9mm 4.1g` 这种样子 |
| 铸造年代 | 印，下面第一行 | 例如：汉武帝元狩五年至元鼎二年 |
| 公元年 | 印，下面第二行，和朝代同一行填写 | 例如：前118年 |
| 备注 | 不印 | 只在列表里提醒自己 |

一条钱币只印一张标签。

点 **保存这条**。勾着「保存后保留本条数据」时，刚填的字会全部留在表单里，改一改再保存，就是下一条。去掉勾，保存后表单会清空。

打开页面时，右边那张示例会先显示第一条钱币，不会空着。你一开始打字，它就改成你正在填的内容。

- **修改**：把这条再填回左边。
- **复制**：照着这条再录一条，改完保存才会多出一条，原来的还在。
- **删除选中**：删掉勾上的。上一份会留在 `data\coins.bak.json`。

第一次打开，里面有两条从原来 PSD 里带进来的示例，可以改，也可以删。第二条的文字请你核对后再打印。

## 怎么打印

1. 勾选要印的钱币。可以点「勾上未打印的」。
2. 点 **看排版并打印**。左边是按钮和说明，右边是竖着的一整张 A4。
3. 看纸上的排列。间距可以选：
   - 省纸：间距 2 毫米，一张 A4 大约 48 张
   - 好裁：间距 3 毫米，大约 44 张
   - 宽松：间距 4 毫米，大约 44 张
4. 点 **开始打印**。
5. 打出来之后，如果没问题，点「确定」，这些就会标成「已打印」。

四周故意留了空白（左右大约 9 到 12 毫米，上下大约 14 到 21 毫米），免得打印机吃掉最外面一圈。

打印窗口里请这样设：

1. 纸张：A4，方向：纵向
2. 边距：无
3. 缩放：100%（不要选「适合页面」）
4. 勾选：背景图形（不然标签是白底）
5. 取消：页眉和页脚

标签底是浅金色，上面的字是纯黑色。外圈黑线用来下刀，里面有一条细金线。不想要这圈线，就关掉「显示裁切边框」。

## 标签有多大

和 `docs\五铢-114.psd` 一样：

- 宽 44.97 毫米，高 20.51 毫米
- 大字是 10 磅，小字是 6 磅
- 原来的整页 PSD 一页只放了 3 张。现在一页大约能放 44 到 48 张。

字太长时，程序会自动缩小。再放不下，页面会提醒你写短一点。

标签上的字用的是原来 PSD 里的「创艺繁隶书」。你这台电脑上，字体文件在 `web\fonts\ctlishu.ttf`，打开网页就会用它。这个字体是买来的，公开仓库里没有放字体文件。别人下载后，如果电脑里没有这个字体，页面会改用系统自带的隶书。

## 数据放在哪

- 正在用的：`data\coins.json`
- 上一份：`data\coins.bak.json`（每次保存前自动留一份）
- 读坏时：`data\coins.bad.json`

可以用「下载备份」把列表存到别的地方，换电脑时用「从备份恢复」。

不要删除 `data` 文件夹。删了，录入的钱币就没了。

## 文件是干什么的

- `启动标签工具.bat`：双击它来打开工具
- `server.py`：在本机开网页，并负责保存数据
- `web`：页面
- `docs`：原来的 PSD，只作样子参考，程序不会改它
- `data`：你录入的钱币

## 常见问题

**网页打不开。**  
看黑窗口里的字。确认地址是 `http://127.0.0.1:8765`。如果提示找不到 Python，先安装 Python，并勾选加入 PATH。

**标签底是白的。**  
打印时没有勾「背景图形」。

**边上被切掉一截。**  
边距要选「无」，缩放要 100%，并关掉页眉页脚。

**字和原来的 PSD 不像。**  
刷新网页后再看。你这台电脑用的是 `web\fonts\ctlishu.ttf` 里的创艺繁隶书。从公开仓库下载的版本没有这个字体文件，会改用系统里的隶书。

**不小心删了。**  
把 `data\coins.bak.json` 复制备份，或用「从备份恢复」。如果文件被改坏，去看 `data\coins.bad.json`。
